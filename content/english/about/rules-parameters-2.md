## General Parameters of the foopgp Association

---

This document aims to gather all the parameters governing the operation of the foopgp association, including those described in its [internal regulations](/fr/about/rules-of-procedures-2/).

### Values in effect until June 30, 2024 (cf. [AGE of October 22, 2023](/fr/assembly/2023-10-22-report-age/))

| Parameter  | Value | Description |
|------------|-------|-------------|
| *fee*      | €1    | Membership fee, see article 3 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *stingynalty*  | 1  | Inflation factor, see article 4 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *growth*   | 0%    | Autonomous growth rate of token quantity, see article 5 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *taxe*     | 0%    | Mandatory contributions, see article 7 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *sharp*    | 1     | Power exponent, see article 8 of the [internal regulations](/fr/about/rules-of-procedures-2/). |

### Values in effect from July 1, 2024 (cf. [AGE of March 24, 2024](/fr/assembly/2024-03-24-report-age/))

| Parameter  | Value              | Description |
|------------|--------------------|-------------|
| *fee*      | €1                 | Membership fee, see article 3 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *stingynalty*  | 1 + 5‰/month   | Inflation factor, see article 4 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *growth*   | 4‰/month           | Autonomous growth rate of token quantity, see article 5 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *taxe*     | 1%/year            | Mandatory contributions, see article 7 of the [internal regulations](/fr/about/rules-of-procedures-2/). |
| *sharp*    | 3/4 = 0.75         | Power exponent, see article 8 of the [internal regulations](/fr/about/rules-of-procedures-2/). |

### Number of Tokens for an Initial Donation

These tables help understand the quantity of tokens created by an initial donation.

This quantity depends on the inflation factor *stingynalty*, which is reevaluated at each change of month.

See article 4 of the [internal regulations](/fr/about/rules-of-procedures-2/).

*Note:* the word *stingynalty* is a contraction of the English words *stingy* and *penalty*. This inflation factor can be considered as a malus against stinginess.

*Note for generating these tables:*

```
git clone https://github.com/foopgp/bash-libs/

cd bash-libs

source ./bin/bl-foopgp --help

BL_FOOPGP_STINGYNALTY=1

for ((i=0;i<12;i++)) ; do
  echo -e "\n####\n"
  BL_FOOPGP_STINGYNALTY=$(bc -l <<<"$BL_FOOPGP_STINGYNALTY+$BL_FOOPGP_STINGYNALTY*5/1000")
  echo -e "***stingynalty* = $BL_FOOPGP_STINGYNALTY**\n"
  bl_foopgp_giftarray
done
```
